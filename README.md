# PROYECTO-SEMINARIO-2026-ECCI
Este repositorio se basa en el desarrollo de un sistema integral de control de movimiento lineal de alta precisión para aplicaciones educativas e industriales, integrando los ejes X, Y y Z mediante control con ESP32 y PLC Siemens, además de tecnologías como automatización industrial y asistencia inteligente mediante interfaz Nextion con chatbot.

#CARACTERISTICAS
✅ Control preciso de movimientos en los ejes X,Y y Z.
⚙️ Motores paso a paso.
🧠 Control dual: PLCs industriales o con ESP32.
🧭 Sensores Inductivos PNP
🔧 Guías lineales y tornillos de bolas que aseguran movimientos suaves y precisos.
